# Explainability-First Clinical Intelligence (EFCI)

EFCI is an explainability-first, multi-agent AI system built using Kiro.
It helps healthcare professionals understand *why* clinical information,
documentation, and workflows exist—without providing medical advice,
diagnosis, or treatment recommendations.

## Key Innovation
- Reason graphs instead of summaries
- Multi-agent orchestration using Kiro
- Confidence-calibrated explanations
- Safety-first design with strict boundaries

## Responsible AI Commitment
- Uses only synthetic and publicly available data
- Explicitly prevents medical advice or decision-making
- Includes audit trails, safety monitoring, and traceability

## Disclaimer
This system is intended for educational and workflow transparency purposes only.
It does not provide clinical decision support.
